GFM står for "GitHub Flavored Markdown" og er en slags dialekt av Markdown som er spesifik til Github. 

Noen ting som gjør at GFM skiller seg ut fra Markdown 
* Du kan bruke extensions, I hvert fall på Visual studio
* Basen av GFM er CommonMark
* GFM lagte til tables, task lists, striketrough, autolinks, fenced code blocks og syntax highlighting
